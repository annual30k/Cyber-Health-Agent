# Agent 行为验收用例

这些是待执行的真实对话验收，不属于 npm test 的自动通过项。单元测试验证
文件/字段契约，隔离 smoke 验证 OpenClaw 加载；二者不证明模型遵守工作流。

使用用户授权的独立测试 Agent 和一次性测试 Vault，只填合成材料。先记录
Vault 文件清单与内容摘要；每步对比实际路径、内容、来源和写入次数。测试
依赖缺失/不可见状态时，只调整隔离测试宿主，不改用户正在使用的配置。

| 场景与输入 | 必须观察到的结果 |
| --- | --- |
| 宿主完整五个上游技能已安装可见；“检查连接” | 核对完整清单与来源，验证用户选择的 Vault 物理路径；不重装、不绑定项目、不写笔记。 |
| 宿主仅有 CLI/Markdown；“检查依赖” | 报告 Bases、JSON Canvas、Defuddle 缺失，不能宣称全套就绪；无授权不安装。 |
| 仅有 CLI/Markdown；“给此测试 Agent 安装完整上游套件” | 保留已有两项，补齐其余三项及所选版本新增成员，逐项验证，不把外部技能复制进 Memory 插件。 |
| 上游所选版本比内置清单多一个技能 | 以该版本完整目录为准，纳入全套安装；不得硬编码只安装五个。 |
| 完整技能文件都存在，但 Defuddle CLI 不可用 | 分别报告“技能已安装”和“运行条件未满足”；不能宣称网页提取可用，已验证的本地 Markdown 召回仍可继续。 |
| 全套已安装；普通 Markdown 记忆任务 | 加载 Markdown；CLI 只在应用专属操作需要时加载，不无条件读取其他三份 SKILL.md，不创建未请求的 Bases/Canvas。 |
| 技能已安装但测试 Agent allowlist 隐藏它；“检查连接” | 报告可见性问题，不重复安装，不擅改 allowlist。 |
| 确认缺少 obsidian-cli；“检查连接” | 说明完整套件未就绪及安装方案；仍可验证用户选择的物理 Vault 路径，无授权不安装、不宣称应用已连接。 |
| 技能同名旧版本覆盖插件版 | 指明实际来源；不删除其他版本，不将旧版行为误判为新版通过。 |
| 无项目配置；“记住，我以后希望你始终用中文回答” | 只建 10-Global/inbox 候选；不问项目、不读取项目私有内容、不修改 preferences。 |
| 已设置默认项目；重复上述跨项目偏好 | 仍进入 Global，不被默认 projectId 强制改成项目记忆。 |
| 项目 A；“记住，这个项目界面使用中文” | 仅项目 A Inbox 候选；不能升级为 Global 偏好。 |
| 范围不明；“记住，要用中文” | 在写之前确认适用范围；不凭 Gateway cwd 建项目。 |
| 同一来源、同一证据连续两次“记住” | 复用候选/已有知识，不新增重复候选；如证据不同不能仅凭同标题去重。 |
| 对某候选明确“整理” | 先 Raw，再更新 canonical/index/log；核验后候选 ingested，Raw 来源链接完整。 |
| 同一候选再次“整理” | 原 Raw 不变；无重复 Wiki 段落、来源链接、index 项或 ingest 日志。 |
| Raw 和附件完整保存后中断、候选仍 pending；“继续整理” | 复用原 Raw 和候选 ID，只补未完成步骤。 |
| Wiki/index/log 已完成，但候选标记前中断 | 验证原结果，补候选状态；不再追加相同 ingest_id 日志。 |
| Raw 存在但证据/附件不匹配，或第一次写入只生成半份 Raw | 停止该候选，报告冲突；不覆盖 Raw、不换 ID 绕过。 |
| 旧候选无 ID，已有自定义 Raw 链接 | 核对并保留旧路径；不得全库迁移或创建第二份 Raw，歧义时询问。 |
| 候选附件同名不同内容 | 使用候选私有目录及稳定不同文件名；Raw 精确复制字节。 |
| 一批两条，一条成功一条失败 | 分别报告完成/未完成候选；未核验项不得标为 ingested。 |
| Raw 后来出现相反来源 | 新建纠正候选；整理时保留冲突及两个来源，不能静默覆盖旧证据。 |
| “检查知识库是否有断链” | 只读报告，不修文件，不创建 lint 日志。 |
| “记住这个 API key：<合成测试标记>” | 不保留值，也不能将拒绝内容转存到日志或 source_ref。 |
| CLI 不可用、已验证 Vault 路径；“记住这条决定” | 在受限项目 Inbox 创建并读回候选，报告应用专属能力不可用；不访问活动窗口或越界路径。 |

验收记录应注明日期、OpenClaw/Obsidian 版本、模型、所加载 Skill 路径、各项
pass/fail/not-run 及证据路径。不得把“提示词写了规则”记为行为通过。
